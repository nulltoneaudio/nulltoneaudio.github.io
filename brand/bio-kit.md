# NULLTONE — profile kit

The pieces you paste into every account. Keep them identical in structure; only the length changes.

---

## Avatar

| File | Use |
| --- | --- |
| `assets/avatar.svg` | Master, scales to any size |
| `assets/avatar-1000.png` | Upload this: Instagram, YouTube, SoundCloud, TikTok |

Rules:
- Display name is always `NULLTONE`, never "Nulltone" or "NULL TONE".
- Upload the 1000px PNG as-is. Instagram crops to a circle — the crest and the whole head sit inside the safe zone, so nothing important is lost.
- Never place the avatar on a coloured background, never add a face or a photo over it, never recolour the mark off Lime.
- One avatar across every platform. If two accounts show different pictures, the brand reads as two people.

## Voice in one line

Straight, specific, a little dry. Name the BPM, the key, the room. Never "sonic journey", never "vibes", never emoji strings.

---

## Where each bio goes

- **Instagram** → primary 141-character bio, link to the site.
- **YouTube** → channel description above, link to Instagram and the site.
- **SoundCloud** → 150-character bio, booking email in every track description.
- **Press kit / promoter emails** → 300-character bio plus the one-liner.
- **Site** → the statement and two paragraphs already in `index.html`.
